Zasoby wspolne dla desktop i Android. Grafika (kafelki, ikony, postacie) jest generowana proceduralnie
w kodzie (`core/.../render/TileArt.java`); pliki PNG w `assets/art/` zastepuja wybrane obrazki
(lista nazw: docs/GRAPHICS.md). Dane gry (przedmioty, kafelki, mapy) leza w `shared/src/main/resources`.
