Grafiki od grafikow. Plik PNG o nazwie z listy w docs/GRAPHICS.md (np. monsters/wolf.png,
characters/paladin_down.png, items/health_potion.png) zastepuje obrazek generowany przez kod.
Brakujace pliki zostaja wygenerowane, wiec mozna podmieniac po kawalku. 16x16 albo 32x32 px.

Obecne pliki: OpenTibia Sprite Pack, licencja CC BY 4.0 (LICENSE-OTSP.txt), autorzy w docs/CREDITS.md.
Wygenerowane skryptem tools/art/otsp_import.py z plikow client_files paczki
(https://github.com/peonso/opentibia_sprite_pack); zmiany: wyciecie, przyciecie, kolory strojow.
